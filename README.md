# WHO Diabetes Data Analysis

A notebook-based analysis of WHO diabetes prevalence data by year, indicator, sex, age group, country, and region.

## Analysis

The notebook calculates descriptive statistics (minimum, maximum, mean, median, mode, and standard deviation) and visualizes yearly trends, prevalence by indicator and age group, top countries, and regional averages.

## Run

Open `UAS_BigData.ipynb` in Google Colab or Jupyter. The notebook reads an Excel workbook from a Google Drive path; update the `path1` value in the first code cell to point to your dataset before running it.
